# 戰鬥模型修正（攻速公式、上限、雲陶狂箭、接斧比例）

日期：2026-09-16
狀態：已核准，待實作
前置：`2026-09-15-champion-kits-design.md`、`2026-09-15-item-passives-design.md`

## 1. 起因

使用者質疑達瑞文的推薦過度偏攻速（雲陶狂箭 → 護脛 → 臨界點，總攻速 2.18）。
逐項查證後：**兩項原本就是對的、兩項是錯的、一項是高估、一項是假設不準**。

## 2. 查證結果（附佐證，避免日後被「好心」改壞）

| 項目 | 結論 | 佐證 |
|---|---|---|
| 達瑞文 Q 加傷是否吃暴擊 | **不吃 —— 現況正確，不改** | 官方維基把 Spinning Axe 列在「基本攻擊修飾」：「這些強化普攻⋯不受暴擊傷害倍率影響，只有底下的普攻本體仍可暴擊」。使用者敘述一致：Q 加傷 100 不變、普攻 100 → 175 |
| 臨界點明暗是否互斥 | **可同時 —— 現況正確，不改** | 維基：交替命中，光明 3 層雙抗與黑暗 3 層雙穿可同時存在 |
| 攻速公式 | **錯** | 維基：`總攻速 = 基礎攻速 + 加成% × 攻速係數`。多數英雄係數 = 基礎攻速故等價，**凱爾例外**（係數 0.667、基礎 0.625） |
| 攻速上限 | **錯** | 維基全文唯一上限數字為 **3.003（所有單位）**；無 2.5 之說（文中唯一的 2.5 是崔絲塔娜成長值）。我們寫死 2.5 |
| 雲陶狂箭 30% 攻速 | **高估** | Flurry：對英雄普攻觸發、持續 6 秒、冷卻 30 秒，每次命中減 1 秒、暴擊減 2 秒。我們當常駐 |
| 達瑞文接斧比例 | **假設不準** | 使用者（本專案的目標玩家）：斧頭滯空時間固定，實戰約 70–80% 的普攻帶斧 |

敏感度實測（fixture，達瑞文 vs 脆皮）：即使假設 Q 完整暴擊，雲陶狂箭仍是第一件
（無盡由第 6 件提前到第 3 件）—— **偏攻速不是暴擊算錯造成的**，而是「Q 加傷固定、
不吃暴擊，模型裡放大 Q 的唯一途徑就是增加攻擊次數」。

## 3. 修正

### 3.1 攻速公式與係數

```
總攻速 = min(上限, 基礎攻速 + (等級成長 + 裝備 + 被動 + 技能) / 100 × 攻速係數)
```

- 係數來自英雄 bin `CharacterRecord.attackSpeedRatioModifiable`（實測：達瑞文 0.679、
  煞蜜拉 0.658 皆等於基礎攻速；凱爾 0.667 ≠ 0.625）
- `ChampionSpells` 新增 `attack_speed_ratio`；kit 透過 `ChampionKitView` 提供
- **無技能模型的英雄係數 = 基礎攻速**，與現行公式完全等價（既有測試數值不變）
- fixture 裁剪需保留 `CharacterRecord`（原本只留 `mSpell`）

### 3.2 攻速上限

`AS_CAP` 2.5 → **3.003**，docstring 註明出處與「2.5 是舊值」。

### 3.3 雲陶狂箭 Flurry 持續率

以冷卻實算（`item_effects`，數值全部讀自 bin）：

```
每秒冷卻縮減 = 攻速 × (1 + 暴擊率)      # 每次命中 −1 秒、暴擊再 −1 秒
就緒時間     = 冷卻 ÷ (1 + 每秒冷卻縮減)
持續率       = min(1, 持續秒數 ÷ max(持續秒數, 就緒時間))
```

例：攻速 2.0、暴擊 50% → 就緒 30 ÷ 4 = 7.5 秒 → 持續率 6 ÷ 7.5 = 0.8。

- 需要當下攻速 → `StatSheet` 補 `attack_speed_base` 與 `attack_speed_ratio`，
  並提供 `attack_speed` 屬性（供效果估算；上限同 §3.2）
- 效果階段由「屬性轉換」移到「傷害類」，才讀得到裝備攻速；**技能提供的攻速
  （達瑞文 W、凱爾被動、煞蜜拉 E）在 kit 之後才加入，估算時尚未計入 —— 近似，寫 docstring**
- bin 數值名稱：`Cooldown`／`ASDuration`／`AACDR`／`CritCDR`（實作時確認；缺名即綁定失敗）

### 3.4 達瑞文接斧比例預設

`config/kits/Draven.toml` 的 `q_empowered_attack_ratio` 1.0 → **0.75**
（使用者實戰 70–80%；註解寫明區間與「調低＝你接不到那麼多」）。

**不做**：接斧比例隨攻速衰減（使用者選擇固定值 —— 斧頭滯空時間固定，與攻速無直接關係）。

## 4. 預期影響與驗收

- 凱爾攻速上升（係數修正）；達瑞文 Q 每次普攻的貢獻下降 25%
- 三隻英雄的規劃黃金快照可能改變 —— 實測後更新，並在
  `2026-09-14-build-optimizer-design.md` §8 記錄新舊序列與原因
- 三隻推薦彼此不同的斷言必須持續成立

## 5. 測試

- 攻速公式：凱爾 +100% 加成 → 0.625 + 0.667 = 1.292（非 1.25）；達瑞文與煞蜜拉
  係數等於基礎攻速故數值不變；無 kit 英雄公式等價
- 上限：3.003 封頂；既有「上限 2.5」測試改為 3.003
- Flurry：攻速 2.0／暴擊 50% → 0.8；攻速極低 → 持續率趨近 6/30；封頂 1.0
- 接斧比例：設定檔預設值 0.75；0 與 1 的 DPS 差距為線性
